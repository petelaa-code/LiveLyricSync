# LiveLyricSync – Architecture Overview

This document describes the high-level architecture of the LiveLyricSync system, including data flow, components, and responsibilities.

---

## 🧩 System Overview

LiveLyricSync consists of two main parts:

1. **PC Server**
2. **Web Client (tablet / phone / browser)**

The server performs audio analysis and alignment, while the client displays synchronized lyrics.
